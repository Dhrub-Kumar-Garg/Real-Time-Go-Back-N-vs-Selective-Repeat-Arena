📖 Sliding Window Protocols: GBN vs. SR

Computer Networks — Module 3 (Data Link Layer Flow Control)

1. The Core Problem: Flow Control & Reliability

In a noisy communication channel, packets may be lost, corrupted, or delayed. Stop-and-Wait protocol achieves correctness but suffers from terrible throughput ($U \ll 1$). Sliding-window protocols allow the sender to transmit up to $W$ unACKed packets before stopping, filling the bandwidth-delay product (BDP) pipe.

2. Window Architecture Comparison

Go-Back-N (GBN) Window
Sender Window [base .. base + W - 1]
[ 0 | 1 | 2 | 3 ] 4   5   6   7 ...
  └─── W = 4 ───┘
• 1 Logical Timer running for base (0).
• Receiver Window size = 1 (accepts ONLY expectedSeq).
• Out-of-order packets are DISCARDED.
Selective Repeat (SR) Window
Sender Window [sendBase .. sendBase + W - 1]
[ 0 | 1 | 2 | 3 ] 4   5   6   7 ...
  └─── W = 4 ───┘
• N Independent Timers (one per in-flight packet).
• Receiver Window size = W (buffers out-of-order).
• Flushes consecutive prefix when gaps fill.

3. Detailed Technical Comparison Table

Dimension Go-Back-N (GBN) Selective Repeat (SR)
ACK Semantic Cumulative ACK: ACK(n) confirms all packets ≤ n Individual ACK: ACK(n) confirms only packet n
Receiver Window Size 1 (no buffering) W (buffers packets in [rcvBase .. rcvBase + W - 1])
Out-of-Order Policy Discard and re-send duplicate ACK for expectedSeq - 1 Store in buffer slot; flush in-order prefix when gap fills
Sender Timers 1 Timer (protects the oldest unACKed packet `base`) 1 Timer per packet (started independently on send)
Retransmission Scope Entire Window [base .. nextSeq - 1] Only the specific timed-out packet
Sequence Number Space W ≤ 2m - 1 W ≤ 2m-1 (prevents overlap ambiguity)
Bandwidth Efficiency under Loss Lower (wastes link capacity on re-sending intact packets) Higher (optimal retransmissions only)
Implementation Complexity Minimal (simple receiver logic) Moderate (buffer array management and re-ordering)
Typical Real-World Use Low error rate links, embedded IoT memory-constrained devices High bandwidth-delay channels, satellite links, TCP SACK
